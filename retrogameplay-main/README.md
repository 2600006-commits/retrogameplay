# Retro Web Arcade

순수 HTML, CSS, Vanilla JS만으로 제작된 정적 레트로 아케이드 에뮬레이터 웹사이트입니다. 빌드 과정 없이 즉시 GitHub Pages에 배포할 수 있도록 설계되었습니다.

## 주요 기능
- **순수 바닐라 환경**: React, Vue, Vite 등 빌드 도구 없음.
- **클라이언트 사이드 처리**: 롬 파일은 서버로 전송되지 않고 브라우저 메모리 내에서 실행됨.
- **SPA 라우팅**: `#` 해시를 이용한 부드러운 화면 전환.
- **반응형 디자인 & 디바이스 감지**: 모바일 터치 패드 자동 활성화.
- **레트로 CRT 효과**: 글래스모피즘 기반 UI와 On/Off 가능한 스캔라인/비네트 필터.

## 로컬 실행 방법 (중요)
에뮬레이터 엔진(`EmulatorJS`)은 브라우저 보안(CORS) 정책상 `file://` 프로토콜로 직접 열면 동작하지 않을 수 있습니다. 반드시 로컬 웹 서버를 구동하여 확인하세요.

**방법 1: VSCode 확장 프로그램 사용**
1. VSCode에서 `Live Server` 확장을 설치합니다.
2. `index.html` 파일을 우클릭하고 `Open with Live Server`를 클릭합니다.

**방법 2: Python 내장 서버 사용 (터미널)**
```bash
# 프로젝트 폴더로 이동 후 실행
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 트러블슈팅: 화면이 검은색으로만 나오고 게임이 실행되지 않을 때

1. **EmulatorJS CDN 주소 확인**: `js/emulator.js`의 `EJS_pathtodata`와 `loader.js` 스크립트 경로가 반드시 공식 CDN(`https://cdn.emulatorjs.org/stable/data/`)을 가리키고 있어야 합니다. 다른 임의의 npm/jsdelivr 경로는 코어 데이터가 존재하지 않아 검은 화면만 뜨는 원인이 됩니다.
2. **"Play" 버튼 클릭 필요**: 브라우저의 자동재생(오디오) 정책 때문에 EmulatorJS는 화면에 재생 버튼을 먼저 띄우고 사용자가 직접 클릭해야 실제 게임이 시작됩니다. 검은 화면 위에 작게 표시되는 버튼을 클릭해보세요.
3. **개발자 도구(콘솔) 확인**: `F12` → Console 탭에서 404 에러나 CORS 에러가 있는지 확인하면 원인을 빠르게 좁힐 수 있습니다.
4. **롬(zip) 파일 형식 확인**: 코어가 요구하는 정확한 버전의 롬셋(예: MAME 2003은 MAME 0.78 기준 롬셋)이어야 정상 동작합니다.
