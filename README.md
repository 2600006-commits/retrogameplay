# Retro Web Arcade

순수 HTML, CSS, Vanilla JS만으로 제작된 정적 레트로 아케이드 에뮬레이터 웹사이트입니다. 빌드 과정 없이 즉시 GitHub Pages에 배포할 수 있도록 설계되었습니다.

## 주요 기능
- **순수 바닐라 환경**: React, Vue, Vite 등 빌드 도구 없음.
- **클라이언트 사이드 처리**: 롬 파일은 서버로 전송되지 않고 브라우저 메모리 내에서 실행됨.
- **SPA 라우팅**: `#` 해시를 이용한 부드러운 화면 전환.
- **반응형 디자인 & 디바이스 감지**: 모바일 터치 패드 자동 활성화.
- **레트로 CRT 효과**: 글래스모피즘 기반 UI와 On/Off 가능한 스캔라인/비네트 필터.

## 로컬 실행 방법 (중요)
에뮬레이터 엔진(`EmulatorJS`)은 브라우저 보안(CORS) 정책상 `file://` 프로토콜로 직접 열면 동작하지 않을 수 있습니다. 반드시 로컬 웹 서버를 구동하여 확인하세요.

**방법 1: VSCode 확장 프로그램 사용**
1. VSCode에서 `Live Server` 확장을 설치합니다.
2. `index.html` 파일을 우클릭하고 `Open with Live Server`를 클릭합니다.

**방법 2: Python 내장 서버 사용 (터미널)**
```bash
# 프로젝트 폴더로 이동 후 실행
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
